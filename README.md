# QurbaniHat 🐄

A modern livestock marketplace for Qurbani animals in Bangladesh.

## Live URL
[https://a-08-project.vercel.app/](https://a-08-project.vercel.app/)

## Features
- Browse cows and goats for Qurbani
- Sort animals by price
- User authentication (Email + Google OAuth)
- Animal booking system
- Profile management
- Fully responsive design

## npm Packages Used
- next
- better-auth
- @heroui/react
- tailwindcss
- react-hot-toast
- lottie-react
- framer-motion

## How to Run Locally
```bash
git clone https://github.com/mdmonimul95-crypto/A-08-project
cd qurbani-hat
npm install
npm run dev
```
